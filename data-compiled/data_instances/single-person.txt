# VitalGraph example: One person across three certificates
#
# This example uses placeholders to show how VitalGraph structures data
# for a single person. The identifier vg:person-001 refers to the same
# person throughout the example.
#
# Default graph: Statements outside the { ... } blocks link the person
# to their birth, marriage, and death events and the corresponding records.
#
# Named graphs: Each block holds the details and relationships reported
# by one certificate.
#   vg:birth-record-001    Birth certificate
#   vg:marriage-record-001 Marriage certificate
#   vg:death-record-001    Death certificate
#
# The same identifier serves two roles. In the default graph,
# vg:birth-record-001 identifies the certificate. Before a { ... } block,
# it names the graph that holds the evidence from that certificate.
##################################################################################
